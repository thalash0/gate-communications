The 14 mistakes that cost the most marks

Factor of 2
  1. Using $N_0$ where the question gives $N_0/2$ (or vice versa); $\sigma^2=N_0/2$ per real dimension.
  2. Forgetting that a cosine carrier halves power: $P=A^2/2$, and modulated PSD has a $\frac14$.
  3. Bandwidth: null-to-null ($2R_b$) vs Nyquist ($R_s$) vs raised cosine $(1+\alpha)R_s$; baseband vs passband.
  4. BER vs symbol-error rate (QPSK $P_s\approx2P_b$).
Units
  1. dB used as a ratio inside $\log_2(1+\mathrm{SNR})$, or $E_b/N_0$ vs $E_s/N_0$ vs per-sample SNR.
  2. Hz vs rad/s ($\omega=2\pi f$): FM/PM $\Delta f$ and $k_f$ units.
  3. Answer asked as ratio vs dB (2021 Q.52!).
  4. Adding standard deviations instead of variances; adding powers in dB.
Conceptual
  1. Thinking "uncorrelated ⇒ independent" or "PSD depends on phase".
  2. Applying $P_c(1+\mu^2/2)$ to FM (power is $A_c^2/2$).
  3. Applying $6.02n+1.76$ to a signal that is not a full-scale sine.
  4. Using the exact $Q$ when the question hands you an approximation (2014, 2026).
  5. Claiming spreading or coding gain on an AWGN link that has neither jammer nor code; or forgetting the code rate when converting $E_b$ to $E_c$.
  6. Counting $d_{\min}$ from pairs of code words instead of the minimum weight (linear codes), or $t=d_{\min}/2$.
Exam-day checklist
  • Write $Q(1),Q(2),Q(3),Q(4)$, $\log_2e$, $kT_0=-174$ on your scratch sheet in the first minute.
  • Do all one-mark Communication questions first (they are almost all formula-recall or one-step).
  • For every detection/BER question: draw the points, mark thresholds, shade the error regions, count them.
  • For every NAT: re-read what unit, how many decimals; check the answer is physically sensible ($P_e\le1$, $H\le\log_2K$, $\eta\le\frac13$ for AM, code rate $\le1$).

Mock test: 24 marks, 40 minutes

Eight 1-mark and eight 2-mark questions in the style of GATE. Set a timer for 40 minutes, answer every question before opening any solution, then check. Your score is counted in the sidebar progress for this chapter.

A WSS process has autocorrelation $R_X(\tau)=9+4e^{-|\tau|}$. Its variance is ______.

Variance $=R(0)-R(\infty)=13-9=4$.

A carrier of amplitude 10 V is amplitude modulated by a tone with $\mu=0.6$. The total transmitted power in a $50\,\Omega$ load is ______ W.

$P_c=\frac{10^2}{2\cdot50}=1$ W; $P_t=1(1+0.36/2)=1.18$ W.

A single-tone FM signal has $\Delta f=45$ kHz and $f_m=5$ kHz. Carson's bandwidth in kHz is ______.

$2(45+5)=100$ kHz.

A source emits four symbols with probabilities $\frac12,\frac14,\frac18,\frac18$. Its entropy in bits/symbol is ______.

$0.5+0.5+0.375+0.375=1.75$.

The maximum SNR of a 12-bit ADC for a full-scale sinusoidal input is about
  1. 62 dB
  2. 68 dB
  3. 74 dB
  4. 80 dB

$6.02\cdot12+1.76=74$ dB.

BPSK has $P_e=Q(\sqrt{2E_b/N_0})$. For $P_e=Q(3)=1.35\times10^{-3}$ the required $E_b/N_0$ (linear) is ______.

$\sqrt{2\gamma}=3\Rightarrow\gamma=4.5$ (6.5 dB).

The code rate of the (15,11) Hamming code is ______.

$11/15=0.733$.

A 64-QAM system sends 1.5 Mbaud. The bit rate in Mbit/s is ______.

$1.5\times\log_264=9$.

White noise of two-sided PSD $10^{-3}$ W/Hz passes through an ideal low-pass filter of cut-off 500 Hz and then an amplifier of voltage gain 2. The output noise power in watts is ______.

$10^{-3}\times2\times500=1$ W before gain; $\times2^2=4$ W.

An SSB system and a single-tone AM system ($\mu=1$, envelope detection) are both operated with channel SNR $\gamma=30$ dB. The output SNR of the AM system in dB is ______.

FOM of AM $=\frac13$ ($-4.77$ dB): $30-4.77=25.23$ dB (SSB gives 30 dB).

A channel of bandwidth 3 kHz has SNR = 15 (ratio). The Shannon capacity in kbit/s is ______.

$3000\log_2(16)=12$ kbit/s.

A source has four symbols with probabilities 0.5, 0.2, 0.15, 0.15. The average codeword length (bits/symbol) of a Huffman code is ______.

Merge 0.15+0.15=0.3; then 0.2+0.3=0.5; then 0.5+0.5. Lengths 1, 2, 3, 3: $0.5+0.4+0.45+0.45=1.8$.

Equiprobable antipodal signalling at $\pm2$ V is received in Gaussian noise of standard deviation 1 V and detected optimally. The bit error probability is ______ (use $Q(2)=0.0228$).

Threshold 0; half-distance 2; $\sigma=1$: $Q(2)=0.0228$.

A channel of 3 kHz bandwidth carries a raised-cosine signal with roll-off 0.5, with no inter-symbol interference. The maximum symbol rate is
  1. 2000 sym/s
  2. 3000 sym/s
  3. 4000 sym/s
  4. 6000 sym/s

$R_s=\frac{2B}{1+\alpha}=\frac{6000}{1.5}=4000$.

A (7,4) Hamming code is used on a BSC with crossover probability 0.05 and corrects every pattern of at most one error. The probability of correct decoding is ______ (two decimals).

$0.95^7+7(0.05)(0.95)^6=0.698+0.257=0.956\approx0.96$.

Telephone speech is sampled at 8 kHz and coded with 8 bits per sample. The minimum (Nyquist) channel bandwidth in kHz needed for the binary PCM stream is ______.

$R_b=64$ kbit/s; $B_{\min}=R_b/2=32$ kHz.

Mock test B: coding, spread spectrum, OFDM and wireless (14 marks, 20 minutes)

This is not a GATE-pattern test (GATE rarely examines these chapters) but the engineering questions a viva or an interview would ask. Six one-mark and four two-mark questions.

A 7-stage LFSR with a primitive feedback polynomial generates a sequence of period ______.

$2^7-1=127$.

A DSSS system spreads 10 kbit/s with a chip rate of 1 Mchip/s. The processing gain is ______ dB.

$G_p=100$; $10\log100=20$ dB.

An OFDM system has a useful symbol duration of 3.2 µs. The subcarrier spacing is ______ kHz.

$1/3.2\ \mu\text{s}=312.5$ kHz.

The maximum throughput of slotted ALOHA is ______.

$1/e=0.368$ at $G=1$.

The cluster size of a hexagonal system with $i=1$, $j=1$ is ______.

$N=1+1+1=3$.

The free-space path loss over 1 km at 900 MHz is ______ dB.

$32.44+20\log1+20\log900=32.44+59.08=91.5$ dB.

BPSK in flat Rayleigh fading with an average SNR of 30 dB has a bit error probability of ______ $\times10^{-4}$.

$\approx1/(4\bar\gamma)=1/4000=2.5\times10^{-4}$.

Four-branch MRC receives with each branch at 5 dB mean SNR. The mean SNR at the combiner output is ______ dB.

SNRs add: $4\times3.16=12.6$, i.e. $5+6.02=11.0$ dB.

A rate-½ convolutional code with $K=3$ has $d_{\rm free}=5$. The asymptotic soft-decision coding gain is ______ dB.

$10\log(0.5\times5)=3.98$ dB.

A regular (3,6) LDPC code has block length 2400. The number of edges in its Tanner graph is ______.

$nd_v=2400\times3=7200$ (and 1200 check nodes).
